I'm currently working on a pump monitor project that will allow me to remotely monitor and control a water pump. The project is still a work in progress, but I've made some progress so far.

The project consists of the following components:

- 2x NodeMCU v1.0
- 2x LoRa module
- Relay module
- Current sensor
- OLED display

The NodeMCU is the main microcontroller that will be used to control the pump. It is connected to the LoRa module, which will be used to send and receive data wirelessly. The relay module is used to control the pump, turning it on and off as needed. The current sensor is used to measure the current flowing through the pump, allowing me to monitor its operation. The OLED display is used to display information about the pump, such as the current status.

I'm still working on the software side of the project, writing the code that will control the pump and send data over LoRa. I'm also working on the user interface, designing a simple interface that will allow me to monitor and control the pump remotely.

I'm excited to see how the project will turn out and to have a working pump monitor that will make my life easier! Stay tuned for updates on my progress.
